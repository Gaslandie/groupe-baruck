Ce paragraphe montre un texte courant utilisé pour expliquer l’objet d’un communiqué. Le ton reste neutre afin de servir de modèle.

## Développer le message

Le corps peut suivre plusieurs étapes :

1. présenter le sujet ;
2. apporter les éléments nécessaires ;
3. conclure avec une orientation claire.
