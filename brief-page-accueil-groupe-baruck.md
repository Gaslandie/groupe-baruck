> **Important :** cette étape concerne principalement la page d’accueil. Les autres pages peuvent être préparées dans la navigation, mais leur contenu complet n’est pas encore nécessaire.

## 3. Objectif de communication

Le site doit présenter le Groupe Baruck comme un groupe :

- ambitieux ;
- multisectoriel ;
- moderne ;
- structuré ;
- prestigieux ;
- porté par un dirigeant visible et engagé ;
- actif dans les affaires, la création, la communication et l’impact social.

## 4. Direction artistique recommandée

### Style général

Créer une interface :

- premium ;
- cinématographique ;
- institutionnelle ;
- moderne ;
- élégante ;
- avec beaucoup d’espace ;
- avec de grandes images ;
- avec des animations sobres et fluides.

### Couleurs

Les couleurs définitives devront être adaptées aux logos qui seront fournis.

En attendant, utiliser une palette provisoire premium et facile à remplacer :

- fond sombre : noir profond, bleu nuit ou anthracite ;
- texte principal : blanc cassé ;
- texte secondaire : gris clair ;
- couleur d’accent provisoire : doré, bronze ou beige chaud.

Ne pas multiplier les couleurs. La palette doit rester sobre.

### Typographie

Utiliser :

- une police élégante et forte pour les grands titres ;
- une police très lisible pour les paragraphes et les éléments d’interface ;
- un nom du président bien visible, mais sans surcharge typographique.

### Effets visuels

Autoriser uniquement des effets maîtrisés :

- transitions douces ;
- légers zooms sur les images du carrousel ;
- fondus entre les diapositives ;
- apparition progressive des textes ;
- effets de survol discrets ;
- légères superpositions de dégradés.

Éviter :

- les animations trop rapides ;
- les effets 3D excessifs ;
- les particules décoratives inutiles ;
- les couleurs trop brillantes ;
- les textes difficiles à lire sur les images.

## 5. Navigation

La navigation doit fonctionner avec un **menu hamburger sur tous les écrans**, y compris sur ordinateur.

### Comportement souhaité

- Afficher le logo du Groupe Baruck dans une zone fixe et visible.
- Afficher un bouton hamburger permanent.
- Au clic, ouvrir un panneau de navigation latéral.
- Le panneau peut glisser depuis la gauche.
- Sur ordinateur, il peut occuper environ 35 à 45 % de la largeur.
- Sur mobile, il doit occuper presque toute la largeur.
- Ajouter un fond assombri derrière le panneau.
- Prévoir un bouton de fermeture clairement visible.
- Fermer le menu avec la touche `Échap`.
- Bloquer le défilement de la page pendant l’ouverture du menu.
- Permettre la navigation au clavier.

### Éléments du menu

1. **Accueil**
2. **Le Groupe**
3. **JECA**
4. **Espoir de Vie**
5. **Activités**
6. **Projets & Réalisations**
7. **Contact**

> Utiliser **« Projets & Réalisations »** à la place de « Réalisation », car cette formulation est plus claire et plus professionnelle.

### Informations complémentaires dans le panneau

En bas du menu latéral, afficher :

- les deux numéros de téléphone ;
- l’adresse e-mail ;
- éventuellement les liens vers les réseaux sociaux lorsqu’ils seront fournis.

### 6.2. Partie droite — Carrousel des activités

Créer un carrousel visuel intégré directement dans la section Hero.

Chaque diapositive doit contenir :

- une grande image représentative d’une activité ;
- un petit label, par exemple **Nos activités** ;
- le nom de l’activité ;
- une courte phrase descriptive ;
- éventuellement un lien **Découvrir**.

### Fonctionnement

- Changement automatique toutes les **4 secondes**.
- Transition fluide entre les images.
- Effet de fondu ou léger déplacement horizontal.
- Léger zoom progressif sur l’image active.
- Barre de progression ou indicateur visuel du temps restant.
- Numéro de diapositive possible : `01 / 09`.
- Contrôles précédent et suivant discrets.
- Pause automatique lorsque l’utilisateur survole le carrousel.
- Pause lorsque le carrousel reçoit le focus au clavier.
- Navigation tactile par glissement sur mobile.
- Respect de la préférence système `prefers-reduced-motion`.

## 9. Responsive design

### Ordinateur

- Hero divisé en deux colonnes.
- Photo du président à gauche.
- Carrousel à droite.
- Menu latéral ouvert depuis le bouton hamburger.
- Grands titres et images immersives.

### Tablette

- Conserver les deux colonnes si l’espace le permet.
- Réduire légèrement la taille du nom et des boutons.
- Éviter que le texte du carrousel couvre trop l’image.

### Mobile

Sur mobile, empiler les deux parties du Hero :

1. présentation du président ;
2. carrousel des activités.

Le portrait du président doit rester visible immédiatement.

Recommandations :

- hauteur du portrait comprise entre 55 et 70 % de l’écran ;
- carrousel placé juste après ;
- boutons sur une ou deux lignes selon la largeur ;
- menu latéral presque plein écran ;
- coordonnées facilement cliquables ;
- textes courts ;
- aucune animation lourde.

## 11. Recommandations techniques

### Stack

Si aucun projet n’existe encore, la stack recommandée est :

- Next.js ;
- TypeScript ;
- Tailwind CSS ;
- composants réutilisables ;
- images optimisées ;
- animations légères avec CSS ou une bibliothèque déjà présente dans le projet.

Si une stack existe déjà, respecter la structure et les conventions du projet au lieu d’imposer une nouvelle technologie.

### Composants suggérés

```text
Header
SideNavigation
HeroSection
PresidentPanel
ActivityHeroCarousel
GroupIntroduction
ActivitiesGrid
PresidentVision
OrganizationsSection
ProjectsSection
ContactCTA
ContactSection
Footer
```

### Données du carrousel

Les activités doivent être stockées dans un tableau ou un fichier de données facilement modifiable.

Exemple de structure :

```ts
type ActivitySlide = {
  id: string;
  title: string;
  description: string;
  image: string;
  href?: string;
};
```

Ne pas coder les neuf diapositives directement dans le composant si cela rend leur modification difficile.

## 12. Accessibilité et qualité

Prévoir :

- textes alternatifs pertinents pour les images ;
- contrastes suffisants ;
- navigation au clavier ;
- focus visible ;
- boutons suffisamment grands sur mobile ;
- menu accessible ;
- carrousel contrôlable manuellement ;
- pause du carrousel ;
- respect de `prefers-reduced-motion` ;
- images compressées ;
- chargement rapide ;
- absence de décalage visuel important pendant le chargement.

Le carrousel ne doit pas empêcher l’utilisateur de lire le contenu. Les textes doivent rester courts et stables pendant chaque intervalle de quatre secondes.

## 13. Consignes importantes pour Claude Code et Codex

1. Concevoir en priorité une **page d’accueil de démonstration très professionnelle**.
2. Ne pas inventer de chiffres, dates, partenaires, adresses ou réalisations.
3. Utiliser le titre validé **PDG du Groupe Baruck**.
4. Ne pas présenter un texte provisoire comme une déclaration officielle.
5. Prévoir des emplacements simples pour remplacer les logos et images.
6. Afficher la civilité et conserver le nom avec l’orthographe exacte : **MR Djoro Joël Shaloom Krasso**.
7. Afficher les coordonnées exactement comme fournies.
8. Utiliser un menu hamburger latéral sur tous les écrans.
9. Faire du Hero la section la plus travaillée de la page.
10. Programmer le changement automatique des visuels toutes les quatre secondes.
11. Garder un bon équilibre entre l’image personnelle du président et l’identité du Groupe Baruck.
12. Ne pas surcharger la page d’animations.
13. Créer un résultat suffisamment qualitatif pour être présenté directement au client.
14. Ajouter des commentaires uniquement lorsqu’ils facilitent réellement la maintenance.
15. Utiliser des contenus et composants réutilisables afin de simplifier les modifications après le retour du client.

## 14. Critères de validation de la maquette

La première proposition sera considérée comme réussie si :

- le président est immédiatement identifiable ;
- son nom et ses fonctions principales sont lisibles ;
- le Groupe Baruck reste l’identité dominante du site ;
- le carrousel des activités fonctionne correctement ;
- chaque visuel change environ toutes les quatre secondes ;
- les neuf domaines d’activité sont représentés ;
- le menu hamburger fonctionne sur ordinateur et mobile ;
- la page paraît premium sans être surchargée ;
- les coordonnées sont visibles ;
- les contenus provisoires sont faciles à remplacer ;
- la maquette s’adapte correctement aux écrans mobiles ;
- aucun contenu non confirmé n’est présenté comme un fait définitif.

## 15. Résumé de la vision de la page

La page d’accueil doit donner l’impression d’entrer dans l’univers d’un groupe multisectoriel dirigé par une personnalité forte.

La première moitié du Hero valorise **Djoro Joël Shaloom Krasso**, tandis que la seconde moitié montre, par un carrousel visuel, l’étendue des activités du **Groupe Baruck**.

Le reste de la page transforme cette première impression en une présentation structurée du groupe, de ses activités, de son leadership, de ses engagements et de ses futures réalisations.
